## 💫 About Me

> *"In God we trust. All others must bring data."*

<img align="right" alt="Data Analysis" width="400" src="https://user-images.githubusercontent.com/74038190/229223263-cf2e4b07-2615-4f87-9c38-e37600f8381a.gif">

Hi, I'm Arnav 👋 I'm a data analyst focused on turning raw data into clear, actionable insights.

I work primarily with **SQL**, **Python** (Pandas, NumPy, Matplotlib, Seaborn), **Excel**, and **Power BI** to analyze user behavior, revenue metrics, and operational performance. I enjoy working on end-to-end analytics projects — from data cleaning and querying to visualization and business insights.

### 🔍 What I'm Up To:
- 🔭 **Currently Building:** Startup-focused analytics projects
- 🌱 **Learning:** Advanced SQL, dashboarding, and statistical modeling
- 💼 **Working On:** End-to-end analytics — cleaning, querying, visualization, insights
- 🤝 **Open To:** Remote Data Analyst opportunities where data drives real decisions
- 💬 **Ask Me About:** SQL, Python, Power BI, Data Visualization
- ⚡ **Fun Fact:** I trust nothing until I've queried it myself
